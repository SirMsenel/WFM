WFM — GÜNCEL SÜRÜM / HIZLI BAŞLANGIÇ

1. GitHub ZIP dosyasını yeni bir klasöre çıkart ve içindeki proje klasörünü VS Code ile aç.
2. VS Code'daki eski Streamlit ve backend işlemlerini Ctrl+C ile durdur.
3. Bu klasörün terminalinde (Python 3.12 önerilir):

   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt

   Windows için ortamı etkinleştirme: .venv\Scripts\activate

4. Birinci terminalde:
   python -m uvicorn backend:app --host 127.0.0.1 --port 8001

5. Aynı klasörde ikinci terminal aç, ortamı etkinleştir ve çalıştır:
   python -m streamlit run ui.py --server.port 8501

6. http://localhost:8501 adresini aç.
   Demo hesap: moderator / 1234

Güncel sürümün menüsünde Demo Veritabanı ve Geçmiş Hafta Analizi vardır.
Mesai Planı > Tahmin Kaynağı altında dört model ve elle giriş bulunur.
Demo Veritabanı menüsünden hesap değiştirerek personel → TL → WFM akışını dene.

İÇERİK

- data/auth_demo.db: mevcut demo personeller ve kullanıcılar
- data/wfm_demo.db: İlk girişte otomatik oluşturulur. 730 günlük ve 35.040 adet 30 dakikalık sentetik çağrı/AHT,
  talepler, ders-sınav kayıtları, vardiyalar ve planlama verileri
- README.md: ayrıntılı kullanım ve mevcut sınırlar

Örnek veriler sentetiktir. Bu sürümü ayrı klasörde çalıştırarak önce inceleyebilirsin.

GÜNCELLEME / macOS
- Eski uygulamayı iki terminalde Ctrl+C ile durdur.
- Yeni ZIP'i ayrı klasöre çıkar. Mevcut kayıtları korumak istersen eski projenin
  data/wfm_demo.db ve data/auth_demo.db dosyalarının kopyalarını yeni data klasörüne aktar.
- Yeni proje klasöründe:
  python3 -m venv .venv
  source .venv/bin/activate
  python -m pip install -r requirements.txt
- Sonra yukarıdaki backend ve Streamlit komutlarını ayrı terminallerde çalıştır.
  Yalnızca tarayıcıyı yenilemek eski klasörden çalışan uygulamayı güncellemez.

BU GÜNCELLEMEDE
- Dış kaynak vardiyası 10 saat: eski kayıtlı 11 saat kuralı otomatik düzeltilir.
- İnterval: önerilen grafik ve her gün için 48 yarım saat ağırlığını gösteren haftalık tablo.
- Kayıt Seçim: profilleri işaretle, Aktif Yap veya Seçilenleri Sil.
- Vardiya Planı: yeni dönem kartı, şehir haritası, dil ve çalışma biçimi grafikleri.
- Personel listesi: Personel Takip > Personel Listesi.
- Vardiya Saatleri: seçili dönem, elle giriş/geri alma, otomatik izin ve gece kayıtları,
  sınav günleri, ihtiyaç karşılama özeti ve eksik dilimlerin ayrıntısı.
- Otomatik plan: tek kutuda grup sırası; sınav günü önceliği, tarihe göre Bahar/Güz.
  Otomatik atama ihtiyacın üstüne çıkmaz. Kesin/elle kayıtlar fazla oluşturuyorsa gösterilir.
- Talep durumları: olumlu yeşil, ret kırmızı, bekleyen/iletilen sarı.
